# Meteo Viareggio — Android Auto

1. Carica questo repo su GitHub (branch `main`).
2. Tab **Actions** → attendi il job "Build APK" → scarica l'artifact `meteo-auto-debug` (zip con `app-debug.apk`).
3. Installa l'APK sul telefono (consenti origini sconosciute).
4. In Android Auto: Impostazioni → tocca 10 volte la versione → Impostazioni sviluppatore → **Sorgenti sconosciute** attivo.
5. Collega l'auto: l'app compare nel launcher di Android Auto.

L'APK è firmato con la debug key: non è pubblicabile sul Play Store, ma si installa senza problemi.
